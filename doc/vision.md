Automate and speedup the the bug-fixing process for C#/.NET developers of long running, multithreaded applications. 

Given a bugreport in a software system, we implement a iterative debugging [workflow](https://github.com/JaromirProchazka/DotReplay/doc/debugging_workflow_description.md) and automate the lenghthy steps of runtime analyses, finding error cases and creation of unit tests for these cases. 

Developers can thus spent more time on error understanding, updating source code and bugfix validation.
